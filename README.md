# Retail Sales Performance Analysis

## Project Overview
An end-to-end data analytics project analyzing retail sales performance to help management understand revenue, profitability, product performance, and regional trends.

## Business Objectives
- Calculate total revenue, profit, orders, and profit margin.
- Analyze monthly sales trends.
- Compare revenue across product categories and regions.
- Identify top-performing products.
- Recommend actions based on business findings.

## Tools & Technologies
- **Microsoft Excel:** Initial data cleaning and quality checks
- **MySQL:** Data storage, validation, and SQL analysis
- **SQL:** Aggregations, grouping, filtering, CASE statements, and window functions
- **Power BI:** Interactive dashboard, KPI cards, charts, and region slicer
- **Python:** Additional analysis using Pandas and Matplotlib

## Key Results
- Total Revenue: ₹153,550
- Total Profit: ₹54,430
- Total Orders: 50
- Profit Margin: 35.45%
- Average Order Value: ₹3,071

## Key Business Insights
1. March generated the highest monthly revenue at ₹64,950.
2. Electronics was the highest-revenue category at ₹77,000.
3. North generated the highest regional revenue at ₹59,300.
4. Headphones generated the highest product revenue at ₹41,400.
5. Office had the highest category profit margin at 50.58%.

## Recommendations
- Investigate the February revenue decline and March recovery.
- Maintain adequate inventory for high-revenue products.
- Review category-level profitability before changing product strategy.
- Investigate the factors behind East's higher regional profit margin.
- Track revenue and profit margin together when evaluating performance.

## Project Workflow
Raw Excel Data → Data Quality Audit and Cleaning → MySQL Database → SQL Analysis → Python Analysis → Power BI Dashboard → Business Recommendations
